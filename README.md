# mekitsi

Landing page for the mekitsi pop-up in Copenhagen.

- Live: https://mekitsi.club
- Source: single self-contained file, `index.html` (all CSS, JS and images inlined)
- Hosting: GitHub Pages, served from `main` branch root
- Custom domain: `mekitsi.club`, configured via the `CNAME` file and DNS at Cloudflare

To change the site, edit `index.html` and push to `main`. Pages redeploys automatically, usually within a minute.
